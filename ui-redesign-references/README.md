- **"Use illustrated empty states"** → `ref-empty-states-illustrated.png` or `ref-empty-illustrations-set.png`

## Color Direction

The user explicitly requested a **BLUE primary color** change. All green/emerald accents in the current app should be replaced with blue (`#2563EB`). Green should be reserved for success states only (paid, confirmed, active).
